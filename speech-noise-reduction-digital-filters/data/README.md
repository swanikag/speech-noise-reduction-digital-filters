# Speech data
Six 16 kHz mono utterances from the CMU Arctic corpus (speakers `aew`, `axb`), obtained from the example data of
https://github.com/LCAV/pyroomacoustics (`examples/input_samples`, MIT-licensed repository).
The MIT licence of this repository covers the code only. The audio belongs to its original distributors;
check the CMU Arctic licence (http://festvox.org/cmu_arctic/) before redistributing.
